# 小幻影视（Rodel Player）连接与播放教程（Windows 电脑及电视端说明）

> 状态：内部草稿（待配图审定，未公开发布）
> 适用设备：Windows 10 / Windows 11 电脑
> 核验日期：2026-11-07

适合在 Windows 10 或 Windows 11 电脑上看片，愿意一次性买断在线媒体模块以获得高画质与特效字幕体验的电脑用户。

---

## 平台与电视端同名软件说明

现役维护的《**小幻影视（Rodel Player）**》为 **Windows 10/11 电脑专属客户端**（内置高性能 `libmpv` 解码引擎），**官方没有推出 Android TV 智能电视版**。

部分外部清单在「Android TV」一栏提到的「小幻影视」，系早年社区流出的同名安卓电视端旧包，目前无官方网站与持续维护更新。如果你使用的是**智能电视或电视盒子**，建议改用有官方维护的 [AfuseKt TV 版](./afusekt.md)、[VidHub TV 版](./vidhub.md) 或免费的 [网易爆米花 TV 版](./baomi.md)。如果你使用的是 **Windows 电脑**，请继续阅读下方教程（如希望在 Windows 上使用完全免费的软件，也可选用 [网易爆米花 Windows 版](./baomi.md)）。

## 二、添加服务器

连接前请先在电脑浏览器登录本站网页门户，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面（账号权益与设备管理可在导航栏「我的」页查看）。

1. 在门户「播放器接入」页「客户端连接凭据」卡片中复制三样信息（首次进入请先设置专属用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（专门给播放器用的独立密码，不是门户登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及复制按钮]

2. 在小幻影视左侧切换到「在线媒体」，点击右上角加号（或「添加服务」），在弹出的连接器类型中选择 `Emby`。
   [截图占位：小幻影视「在线媒体」页面右上角添加按钮与「Emby」连接器选项]

3. 在添加 Emby 服务窗口中按分栏准确填写：
   - **服务名称**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **协议（Scheme）**：选择 `https`（加密传输连接）
   - **主机 / 地址（Host）**：只填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`），**不要**输入 `https://`
   - **端口（Port）**：填写 `443`（不要填 `8096` 或 `8920`）
   - **路径（Path）**：**保持留空**，不要填写 `/emby`
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：小幻影视添加 Emby 服务弹窗表单，重点框出「协议：https」「主机：纯域名」「端口：443」「路径：留空」与账号密码栏]

4. 点击「确认 / 保存」，软件即会连接本站服务器并同步显示分类媒体库海报墙。
   [截图占位：小幻影视连接成功后加载出的电影与剧集海报墙主界面]

## 三、第一次播放操作

1. 在小幻影视「在线媒体」页浏览分类海报，或使用顶部搜索框搜索影片，点击封面进入详情页。
   [截图占位：小幻影视媒体库分类浏览与顶部搜索栏界面]

2. 点击详情页的「播放」按钮，软件会调用内置的 `libmpv` 解码器开始原画直放（支持 4K HDR 与 ASS 特效字幕）。
   - **播放配置提醒**：请直接使用小幻影视内置的默认播放预设，**不要**随意粘贴网络流传的第三方自定义 `mpv.conf` 配置文件，错误的自定义参数容易引发黑屏或软件闪退。
   [截图占位：小幻影视影片详情页，框出「播放」按钮与视频编码/音轨信息]

3. 播放过程中移动鼠标呼出底部控制栏，可随时切换多语言音轨、选择内封或外挂字幕、切换全屏；关闭窗口后观看进度会自动同步回服务器。
   [截图占位：小幻影视播放窗口底部控制栏，框出音轨、字幕与全屏按钮]

## 四、常见问题排查

1. **在软件里找不到添加 Emby 的入口，或无法保存**
   - 请检查是否已在「在线媒体」页面完成一次性模块解锁；未解锁时仅开放本地文件与基础网盘入口。
2. **添加后加载不出媒体库或报错连接失败**
   - 请核对四点：协议必须是 `https`，主机栏只填纯域名（不含 `https://`），端口必须是 `443`（不能是 `8096`），「路径（Path）」一栏必须留空（不能填 `/emby`）。
3. **点播放后画面黑屏但有声音**
   - 如果之前自行修改过软件设置里的自定义 MPV 参数或着色器配置，请进入小幻影视「设置 -> 播放器」恢复为官方默认预设后重试。
4. **提示用户名密码错误或设备数已满**
   - 账号与播放密码在门户「播放器接入」页查看（可点「修改播放密码」重置）；设备数量达上限时，进入门户导航栏「我的」页，在「我的设备」卡片中移除旧设备。
