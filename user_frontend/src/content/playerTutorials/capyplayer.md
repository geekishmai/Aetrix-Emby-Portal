## 二、添加服务器

连接前请先登录网页门户，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面（账号权益与设备管理可在导航栏「我的」页查看）。

1. 在门户「播放器接入」页「客户端连接凭据」卡片中复制三样信息（首次进入请先设置专属用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（专门给播放器登录使用，不是网页登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及复制按钮]

2. 打开 CapyPlayer，进入资源管理页点击「添加资源 / 添加服务器」，在服务器类型中选择 `Emby`。
   [截图占位：CapyPlayer 添加资源界面，框出媒体服务器类型中的「Emby」选项]

3. 在添加 Emby 表单中逐项填写：
   - **名称**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **HTTPS 开关**：**开启**（`HTTPS` 表示加密传输连接）
   - **主机 / 地址（Host）**：只填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`），**不要**带 `https://`
   - **端口（Port）**：填写 `443`（不要填 `8096` 或 `8920`）
   - **路径（Path）**：**保持留空**，不要填写 `/emby`
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：CapyPlayer 添加 Emby 表单页，重点框出开启状态的「HTTPS」开关、「Host 纯域名」「Port 443」与留空的「Path」栏]

4. 点击「保存 / 连接」，连接成功后即可在资源列表看到本站媒体库。
   [截图占位：CapyPlayer 保存连接后展示的服务器卡片与分类海报列表]

## 三、第一次播放操作

1. 点击已连接的服务器卡片，按分类浏览电影或剧集海报，点击封面进入详情页。
   [截图占位：CapyPlayer 媒体库分类浏览界面]

2. 在影片详情页点击「播放」按钮，等待几秒缓冲即可开始原画播放。
   [截图占位：CapyPlayer 影片详情页，框出「播放」按钮与剧集选集区域]

3. 播放时轻触屏幕呼出控制栏，可切换多语言音轨或中文字幕；退出播放后观看进度会自动同步回门户。
   [截图占位：CapyPlayer 播放控制菜单，框出音轨与字幕切换按钮]

## 四、常见问题排查

1. **保存服务器时提示连接失败或 404**
   - 请检查三处常见错误：一是「HTTPS」开关未打开；二是「Port（端口）」未改成 `443`；三是在「Path（路径）」一栏误填了 `/emby`（路径栏必须留空）。
2. **提示账号或密码错误**
   - 核对填写的是门户「播放器接入」页的用户名和播放密码，不是网页注册邮箱或网页密码；忘记播放密码可在「播放器接入」页点「修改播放密码」重置。
3. **提示登录设备数达到上限**
   - 打开网页门户导航栏「我的」页，在「我的设备」卡片中删除不再使用的旧设备记录后再试。
