# AfuseKt 与 AfuseKtV 连接与播放教程（Android 手机平板 / Android TV 电视盒子）

> 状态：内部草稿（待配图审定，未公开发布）
> 适用设备：Android 手机与平板（安装 `AfuseKt`）、Android TV 智能电视与机顶盒（安装 `AfuseKtV`）
> 核验日期：2026-11-07

适合使用安卓手机平板或 Android TV 电视盒子（含老款 32 位盒子），需要遥控器原生大屏界面与多播放内核切换的用户。

## 一、下载与安装包选择说明（手机与电视请勿混装）

> **术语解释（32 位与 64 位安装包）**：位数代表设备系统处理器的规格。新款安卓手机基本都是 64 位；而市面上很多智能电视和老款电视盒子运行的是 **32 位**安卓系统。如果给 32 位电视装了 64 位安装包，系统会提示「解析软件包时出现问题」。

- **官方下载官网（国内网络可直接下载全部版本 APK）**：[www.afusekt.cn/AfuseKt](https://www.afusekt.cn/AfuseKt/)
- **GitHub 官方发布页**：手机平板版 [AttemptD/AfuseKt-release](https://github.com/AttemptD/AfuseKt-release) · 电视盒子版 [AttemptD/AfuseKtV-release](https://github.com/AttemptD/AfuseKtV-release)
- **费用说明**：软件免费下载，连接 Emby 基础播放免费；在线字幕匹配、多端云同步等进阶特性支持按月/按年订阅或永久买断（参考价约 ¥10/月、¥39/年、¥69 永久标准版、¥99 永久 PRO）。

1. 访问官网 `https://www.afusekt.cn/AfuseKt/`，按设备准确选择安装包：
   - **安卓手机 / 平板**：下载手机版 **`AfuseKt`**；
   - **智能电视 / 电视盒子**：下载电视专用版 **`AfuseKtV`**（如果不确定家里电视是几位系统，优先下载 **TV 32 位**版本，老盒子与新电视大多都能兼容安装；新款高端盒子可选 **TV 64 位**），通过 U 盘或局域网传输安装到电视上。
   [截图占位：AfuseKt 官网下载页面，分别框出「手机版 AfuseKt」「电视版 AfuseKtV 32位」与「电视版 AfuseKtV 64位」三个下载按钮]

## 二、添加服务器

连接前请先在手机或电脑浏览器登录本站网页门户，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面（账号权益与设备管理可在导航栏「我的」页查看）。

1. 在门户「播放器接入」页「客户端连接凭据」卡片中查看三样信息（首次进入请先设置专属用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（专门填在播放器里的独立密码，不是网页登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三项]

2. 打开手机上的 `AfuseKt` 或电视上的 `AfuseKtV`，进入「资源库 / 添加资源」，在媒体服务器类型中选择 `Emby`。
   [截图占位：AfuseKt / AfuseKtV 添加资源界面，框出「Emby」图标]

3. 在添加 Emby 服务器表单中逐项填写：
   - **名称**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **服务器地址**：若为单行完整地址框，填写 `https://emby.fluxquata.com`（帆桥会员填 `https://emby.fanqiao.net`）；若把协议和主机分栏，协议选 `HTTPS`（加密连接），主机填纯域名，末尾**不要**加 `/emby`
   - **端口**：填写 `443`（不要保留默认的 `8096` 或 `8920`）
   - **用户名**：输入门户上的用户名
   - **密码**：输入门户上的播放密码
   [截图占位：AfuseKt / AfuseKtV 添加 Emby 表单界面，重点框出 HTTPS 地址、端口 443、用户名与密码栏]

4. 点击「连接 / 保存」，等待几秒读取本站媒体库海报列表。
   [截图占位：AfuseKt / AfuseKtV 连接成功后的分类海报墙主界面]

## 三、第一次播放与切换播放内核

1. 在首页浏览分类媒体库或搜索片名，点开想看的电影或剧集详情页，点击「播放」按钮起播。
   [截图占位：AfuseKt / AfuseKtV 影片详情页，框出「播放」按钮与剧集选集区]

2. 播放时轻触手机屏幕（电视端按遥控器下键或菜单键），可在底部菜单切换音轨语言与内封字幕。
   [截图占位：播放控制菜单，框出音轨、字幕与播放器内核切换按钮]

3. **遇到画面偏色、无声或特效字幕排版错乱时（切换 MPV 内核）**：
   - **什么是播放内核**：播放内核是软件内部负责解码视频画面的引擎。AfuseKt 内置了 `Exo`、`MPV`、`VLC` 三种内核。
   - 如果某部高码率杜比视界影片在默认 `Exo` 内核下颜色发紫/发绿，或动漫特效字幕显示不全，直接在播放控制栏或设置里将内核切换为 **`MPV`** 即可正常显示。
   [截图占位：AfuseKt 播放设置面板，框出将内核切换为「MPV」的选项]

## 四、常见问题排查

1. **电视安装 APK 时报错「解析软件包时出现问题」**
   - 说明给 32 位电视系统下载了 64 位安装包，或误下了手机版。请回到官网重新下载 **`AfuseKtV` TV 32 位**安装包安装。
2. **连接服务器时提示网络错误或连接失败**
   - 检查地址开头是否为 `https://`、端口是否已改成 `443`，确认没有误填 `http://`、没有保留 `8096`，且末尾没有加 `/emby`。
3. **提示账号密码错误或登录设备已满**
   - 账号与播放密码在门户「播放器接入」页核对（忘记密码可点「修改播放密码」重置）；设备已满时请进入门户导航栏「我的」页，在「我的设备」卡片中移除旧设备。
