## 一、什么是播放器，为什么不能直接在网页里看

**播放器**是安装在手机、平板、电脑或电视上的视频播放软件。网页门户负责浏览海报、查找影片、管理账号；真正的视频画面和声音由播放器负责解码和播放。

本站影片采用高画质原盘与高码率封装（常见单部体积数 GB 至数十 GB，包含 4K、HDR、杜比视界与多声道音轨）。普通浏览器自带的网页播放器不支持大多数高规格音视频格式，如果强行在网页里播放，会出现没有声音、画面偏色或报错无法打开。

本站服务器采用**原画直放**模式（原画直放是指服务器不对视频重新压缩转换，直接把原始画质传给你的设备解码）。安装一款支持 Emby 协议的第三方播放器后，连接一次账号，后续打开软件就能直接选片观看，播放进度也会自动同步。

## 三、连接前准备：从门户获取三样连接信息

无论你选哪一款播放器，连接服务器都只需要准备 **三样信息**：**服务器地址**、**用户名**、**播放密码**。

> **术语解释**：
> - **服务器地址**：播放器用来找到本站片库的网络网址（类似门牌号）。
> - **播放密码**：专门填在播放器里的独立密码，与你登录网页门户的密码互不影响。修改播放密码不会改动网页登录密码。
> - **一键导入**：网页门户自动打开你设备上的播放器，并把服务器地址和用户名填好，省去手动输入。

请按以下步骤在网页门户获取这三样信息：

1. 用手机或电脑浏览器登录门户网站，点击页面右上角的圆形个人头像（或在「我的」页查看账号权益后打开右上角头像菜单），点击菜单第一项「播放器接入」（也可直接点首页右上角的「播放器接入」按钮）。
   [截图占位：门户顶部导航栏与右上角头像下拉菜单，框出「我的」入口与下拉菜单第一项「播放器接入」按钮]

2. 如果是第一次进入「播放器接入」页面，先在页面输入框里设置你的专属「用户名」和「播放密码」，点击保存（注意：用户名设置后不可修改，播放密码后续可以随时重设）。
   [截图占位：「播放器接入」页首次设置区域，框出用户名输入框、播放密码输入框与保存按钮]

3. 设置完成后，在「客户端连接凭据」卡片中可以看到三行信息：**服务器**、**用户名**、**播放密码**。点击每行右侧的复制图标即可逐项复制。
   - 统一服务器地址：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）。
   [截图占位：「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及右侧复制按钮与「修改播放密码」按钮]

4. 如果你安装的是 **VidHub**、**SenPlayer** 或 **Rex**，可以直接点击下方「一键导入到客户端」区域的对应软件按钮，输入一次播放密码后会自动跳转到播放器完成添加。
   [截图占位：「播放器接入」页「一键导入到客户端」区域，框出 Rex、senplayer、VidHub 三个按钮]

5. 后续如果需要查看已登录过哪些设备，或者提示设备数量达到上限，点击顶部或底部导航栏的「我的」，下滑到「我的设备」卡片即可手动移除不再使用的旧设备。

## 四、手动填写时的四条通用核对规则

大多数连接失败都是因为地址或端口多填、漏填了字符。手动输入时请逐条核对：

1. **服务器类型选 `Emby`**：不要选成 Jellyfin、Plex 或 WebDAV。
2. **协议必须用 `HTTPS`（加密连接）**：
   - 如果软件只有一个「地址」输入框，填完整地址：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）。
   - 如果软件把「协议」和「主机/地址」分成两栏，协议选 `HTTPS`，主机栏只填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`），不要再重复输入 `https://`。
   - 地址末尾**不要**加 `/emby`，也**不要**加斜杠 `/`。
3. **端口（Port）必须填 `443`**：
   - **端口**是网络服务的数字通道号，`HTTPS` 加密连接固定使用 `443`。
   - 很多播放器默认填着 `8096` 或 `8920`，切换成 `HTTPS` 后如果没把端口改成 `443`，一定会提示连接失败。
4. **账号填「播放器接入」页的用户名和播放密码**：不要填注册网站用的邮箱，也不要填网站登录密码。

## 五、不推荐与被拦截的播放方式说明

为了保证播放成功率和全站片库稳定，请避开以下使用方式：

1. **不要使用「Infuse 媒体库模式」（会被服务器拒绝登录）**：
   - 本站支持 **Infuse 直连模式**（以及门户影片详情页的「用 Infuse 打开」按钮），但服务器明确拦截 **Infuse 媒体库模式**。
   - 原因：开启媒体库模式后，Infuse 会把全站所有影片逐部预读扫描，短时间内产生大量网盘取链请求，触发网盘风控限流。因此在 Infuse 中添加服务器时，必须展开「高级」选项卡，确认关闭「媒体库模式」开关；如果开启了媒体库模式，服务器会直接拒绝登录。详细步骤见 [Infuse 教程](./infuse.md)。
2. **不推荐使用 Emby 官方客户端、Emby 魔改客户端与浏览器网页直接播放**：
   - 本站已关闭服务器端实时转码（转码是指服务器把高码率视频实时压缩成低画质流），Emby 官方客户端与浏览器解码能力有限，遇到高码率 MKV、杜比视界或特殊音轨时会请求转码并报错 `404` 无法播放。请统一使用上方表格列出的 16 款第三方播放器。
