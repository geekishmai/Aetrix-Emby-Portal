## 二、添加服务器与必改设置

连接前请先登录网页门户，从导航栏「我的」查看账号状态后，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面。

1. 在门户「播放器接入」页「客户端连接凭据」区域复制以下三样信息（首次进入请先设置用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（独立于网页门户登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及右侧复制按钮]

2. 打开 Forward，进入「资源 / 服务器」标签页，点击右上角加号添加服务器，选择类型 `Emby`。
   [截图占位：Forward 添加资源界面，框出右上角加号与服务器类型中的「Emby」选项]

3. 在添加 Emby 服务器表单中按分栏格式准确填写：
   - **名称 / 标题**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **协议（Scheme）**：选择 `HTTPS`（加密连接协议）
   - **主机 / 地址（Host）**：只填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`），**不要**输入 `https://`，末尾也**不要**加 `/emby`
   - **端口（Port）**：填写 `443`（不要保留 `8096` 或 `8920`）
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：Forward 添加 Emby 服务器表单页，重点框出「协议：HTTPS」「主机：纯域名」「端口：443」以及用户名密码栏]

4. 点击「保存 / 连接」，等待软件加载出本站媒体库列表。
   [截图占位：Forward 保存服务器后显示连接成功与媒体库分类的界面]

5. **必做检查（关闭详情页预加载）**：进入 Forward 的「设置 -> 播放设置」，找到「详情页预加载」（`DetailPreload`）开关并**将其关闭**。
   - **什么是详情页预加载**：开启后只要你点开某部电影介绍页、还没点播放，软件就会提前在后台拉取视频流。关闭它可以避免浏览选片时频繁占用你的同时播放名额或触发风控限流。
   [截图占位：Forward 应用设置 -> 播放设置界面，框出处于关闭状态的「详情页预加载」开关]

## 三、第一次播放操作

1. 在 Forward 首页或媒体库分类中点开一部电影或剧集海报，进入详情页。
   [截图占位：Forward 媒体库海报墙界面与选片入口]

2. 点击详情页的「播放」按钮，等待几秒网络缓冲后开始原画播放。
   [截图占位：Forward 影片详情页，框出「播放」按钮与剧集分集卡片]

3. 在播放界面轻点屏幕呼出底部控制条，可按需切换音频轨道（多语言配音）与字幕轨道；退出时观看记录会自动同步回服务器。
   [截图占位：Forward 视频播放控制栏，框出音轨切换与字幕切换按钮]

## 四、常见问题排查

1. **添加服务器时提示无法连接**
   - 检查「协议」是否选了 `HTTPS`、「端口」是否改成了 `443`，以及「主机」一栏是否只填了纯域名 `emby.fluxquata.com`（或 `emby.fanqiao.net`）而没有多填 `https://` 或 `/emby`。
2. **明明只看了一部片，却偶发提示同时播放路数超限**
   - 请按上方第 5 步检查是否还没关闭「详情页预加载」（`DetailPreload`）开关；也可在网页门户「播放器接入」页的「正在播放」区域点击「结束」清理残留会话。
3. **提示账号密码错误或登录设备已满**
   - 账号密码请在门户「播放器接入」页核对或点击「修改播放密码」重设；若设备数已满，请进入门户「我的」页，在「我的设备」卡片中移除旧设备。
