# Infuse 连接与播放教程（iPhone / iPad / Apple TV / Mac）

> 状态：内部草稿（待配图审定，未公开发布）
> 适用设备：iPhone、iPad、Apple TV、Mac、Apple Vision Pro（需安装 Infuse 7.7 及以上版本，推荐最新 8.x 版）
> 核验日期：2026-11-07

适合使用 iPhone、iPad、Apple TV 或 Mac，追求杜比视界与高规格音轨画质且愿意订阅 Pro 的苹果用户。

---

## 重要规则说明（阅读后再连接）

本站支持使用 **Infuse 直连模式**（也支持门户影片详情页的「用 Infuse 打开」按钮），但**严禁开启「媒体库模式」**。

- **什么是直连模式与媒体库模式**：直连模式是指按需即时读取服务器上的海报与视频，不在本地建立全站索引；媒体库模式是指把服务器上的全部影片逐部扫描并缓存到你的设备里。
- **为什么不能开媒体库模式**：开启媒体库模式后，Infuse 会把整个片库逐个预读，短时间内大量触发底层网盘取链请求，带来严重的网盘风控风险。因此服务器开启了自动拦截规则，**开启媒体库模式的 Infuse 会被服务器直接拒绝登录（报错 403 或提示该播放器已被停用）**。
- **官方文档参考**：关于直连模式与媒体库模式开关位置的官方说明，可查阅 Firecore 官方帮助文档：[通过 Plex、Emby 和 Jellyfin 进行串流（中文版）](https://support.firecore.com/hc/zh-cn/articles/360006462093) 以及 [连接信息与客户端标识说明](https://support.firecore.com/hc/zh-cn/articles/21072505575319)。

## 二、连接与播放（两种方式任选其一）

### 方式一：门户详情页直接拉起播放（免配置，最简单）

如果你不想手动填写服务器信息，装好 Infuse 后可以直接从门户网页点播：

1. 用苹果设备自带浏览器登录门户网站，在「首页」或「片库」点开你想看的电影或剧集详情页。
   [截图占位：门户影片详情页，展示影片标题与下方一排操作按钮]

2. 点击标题下方的「用 Infuse 打开」按钮，在系统弹出的提示框中点击「打开」。
   [截图占位：影片详情页框出「用 Infuse 打开」按钮，以及苹果系统弹出的「在 Infuse 中打开此页？」确认框]

3. 系统会自动跳转到 Infuse 并以直连通道开始播放该影片，不会触发媒体库全量扫描。
   [截图占位：Infuse 自动打开并开始加载播放视频的画面]

### 方式二：在 Infuse 内添加 Emby 服务器（关闭媒体库模式）

如果你希望以后直接打开 Infuse 就能浏览本站海报墙和选片，请按以下步骤添加服务器。

#### 第一部分：在门户复制三样连接信息

1. 用浏览器登录门户网站，点击右上角个人头像（或从「我的」页查看权益后点开右上角头像菜单），进入「播放器接入」页面（也可点首页右上角「播放器接入」按钮）。
   [截图占位：门户右上角头像下拉菜单，框出「我的」与第一项「播放器接入」入口]

2. 在「客户端连接凭据」区域查看并复制三样信息（首次进入请先设置用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你在本页设置的专属播放用户名
   - **播放密码**：你在本页设置的播放密码（这是专门给播放器用的密码，不是网页登录密码）
   [截图占位：「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及右侧复制按钮]

#### 第二部分：在 iPhone / iPad / Mac 上添加服务器

1. 打开 Infuse，点击界面右下角的「设置」（齿轮图标），再点击「新增文件来源」。
   [截图占位：Infuse 主界面右下角齿轮图标与设置页顶部的「新增文件来源」按钮]

2. 向下找到「媒体服务器」区域，点击「添加媒体服务器」，在列表中选择「添加 Emby」，再点击底部的「其他 Emby」（不要点上方的 Emby Connect 在线账户登录）。
   [截图占位：Infuse 添加媒体服务器列表页，框出「添加 Emby」及下一步底部的「其他 Emby」按钮]

3. 在填写页面依次输入以下内容：
   - **名称**：随意填写（例如 `主站影院` 或 `帆桥影院`）
   - **地址**：只填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`），**不要**带 `https://`，末尾也**不要**加 `/emby`
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：Infuse 其他 Emby 填写表单上半部分，框出名称、纯域名地址、用户名、密码四行]

4. 点击表单下方的「高级」（Advanced）展开高级选项：
   - **协议（Protocol）**：选择 `HTTPS`（加密传输协议）
   - **端口（Port）**：如果显示端口栏，确认填写 `443`（不要保留 `8096` 或 `8920`）
   - **媒体库模式（Library Mode）**：**必须保持关闭状态（灰色未勾选）**。Infuse 7.7 及以上版本新建连接时默认就是关闭状态（即直连模式），请核对确认不要打开它。
   [截图占位：Infuse 表单展开「高级」选项卡界面，重点框出「协议：HTTPS」与处于关闭状态的「媒体库模式」开关]

5. 核对无误后点击右上角「保存」（或「连接」）。连接成功后会出现本站的分类媒体库列表，点击媒体库右侧的星标即可将其固定到 Infuse 首页。
   [截图占位：Infuse 连接成功后的媒体库列表页，框出分类库名称右侧的收藏星标与右上角完成按钮]

#### 第三部分：在 Apple TV 电视盒子上添加服务器

1. 打开 Apple TV 上的 Infuse，进入顶部菜单「设置」->「共享」，选择「添加媒体服务器」->「添加 Emby」->「其他 Emby」。
   [截图占位：Apple TV 端 Infuse「设置 -> 共享 -> 添加媒体服务器」路径界面]

2. 按上方相同规则填入纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`）、用户名与播放密码，移动遥控器焦点点开「高级」（Advanced），将协议设为 `HTTPS`，并**确认「媒体库模式（Library Mode）」处于关闭状态**，最后点击保存。
   [截图占位：Apple TV 端 Infuse「其他 Emby -> 高级」设置页，框出 HTTPS 与「媒体库模式：关闭」项]

## 三、第一次播放操作

1. 回到 Infuse 主界面，在首页看到刚添加的分类媒体库（如电影、国产剧、欧美剧等），点击进入任意一部影片。
   [截图占位：Infuse 首页直连模式展示的服务器分类行与继续观看栏]

2. 在影片详情页点击「播放」按钮，等待数秒缓冲后即可原画起播。
   [截图占位：Infuse 影片详情页，框出「播放」按钮及下方显示的视频分辨率与音轨标识]

3. 播放过程中如果需要切换国语/原声配音或中文字幕，在屏幕上轻点呼出控制栏（Apple TV 按遥控器下键），在「音频」和「字幕」菜单中切换即可；退出播放时进度会自动同步回门户网站。
   [截图占位：Infuse 播放控制栏展开状态，框出「音频」与「字幕」切换选项]

## 四、常见问题排查

1. **登录时报错「403」「连接失败」或提示「该播放器已被服务器停用」**
   - 原因一：不小心打开了「媒体库模式」，或安装的 Infuse 版本低于 7.7。请先去 App Store 把 Infuse 更新到最新版，再进入「设置 -> 新增文件来源 -> 点击已保存的服务器编辑 -> 高级」，把「媒体库模式」关掉后重新保存。
   - 原因二：地址栏多填了 `https://` 或 `/emby`，或者协议没改成 `HTTPS`。Infuse 地址栏只需填纯域名 `emby.fluxquata.com`（或 `emby.fanqiao.net`），并在「高级」里选 `HTTPS`。
2. **提示用户名或密码错误**
   - 请确认填的是门户「播放器接入」页的专属用户名和「播放密码」，而不是网页注册邮箱或网页登录密码。如果不记得播放密码，可在门户「播放器接入」页点击「修改播放密码」重设一个新密码。
3. **点击播放时提示升级 Infuse Pro**
   - 本站影片多为 4K HDR、杜比视界及高规格多声道音轨，Infuse 免费版对这类编码有功能限制。如需在免费软件上观看，可改用 [网易爆米花](./baomi.md) 或其他支持软件。
4. **提示登录设备数已达上限**
   - 打开网页门户顶部或底部的「我的」页面，向下滑到「我的设备」卡片，移除不再使用的旧设备记录后再重新打开 Infuse。
