# hosplayer 连接与播放教程（华为鸿蒙 HarmonyOS NEXT）

> 状态：内部草稿（待配图审定，未公开发布）
> 适用设备：搭载 HarmonyOS NEXT（纯血鸿蒙 / HarmonyOS 5.0 及以上）的华为手机、平板等设备
> 核验日期：2026-11-07

适合已升级华为纯血鸿蒙系统（HarmonyOS NEXT / 5.0 及以上），需要在华为手机或平板上免费连接片库的用户。

---

## 一、系统版本核对与下载说明

- **下载渠道**：在纯血鸿蒙设备上直接打开华为自带的「应用市场（AppGallery）」，搜索 `hosplayer` 安装（官方商店页：[华为应用市场 - hosplayer](https://appgallery.huawei.com/app/detail?id=com.colorlifee.hosplayer)）。
- **费用说明**：免费。
- **旧版鸿蒙系统提示**：如果你的华为手机或平板系统版本是 **HarmonyOS 4.x 及以下**（仍支持直接安装安卓 APK 应用），在应用市场可能搜不到纯血鸿蒙版 `hosplayer`；这种情况下请直接选用安卓版的 [VidHub](./vidhub.md)、[AfuseKt](./afusekt.md) 或 [网易爆米花](./baomi.md)。

1. 打开华为设备上的「应用市场」，在搜索框输入 `hosplayer`，点击「安装」。
   [截图占位：华为应用市场搜索 `hosplayer` 的应用详情页，框出应用图标与安装按钮]

## 二、添加服务器

连接前请先用华为浏览器登录本站网页门户，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面（账号权益与设备管理可在导航栏「我的」页查看）。

1. 在门户「播放器接入」页「客户端连接凭据」卡片中复制三样信息（首次进入请先设置专属用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（专门填在播放器里的独立密码，不是网页登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及复制按钮]

2. 打开 hosplayer，在首页点击「添加服务器 / 添加媒体源」，选择服务器类型 `Emby`。
   [截图占位：hosplayer 主界面，框出添加服务器按钮与「Emby」选项]

3. 在添加 Emby 服务器表单中逐项核对填写：
   - **名称**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **服务器地址**：若为单行地址框，填写完整加密地址 `https://emby.fluxquata.com`（帆桥会员填 `https://emby.fanqiao.net`）；若分栏填写，协议选 `HTTPS`（加密连接），地址填纯域名，**端口填 `443`**（不要保留 `8096` 或 `8920`），末尾**不要**加 `/emby`
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：hosplayer 添加 Emby 服务器表单界面，重点框出 `https://` 地址、端口 443、用户名与密码栏]

4. 点击「保存 / 连接」，连接成功后即可加载出本站的分类媒体库列表。
   [截图占位：hosplayer 连接成功后展示的分类媒体库与海报列表]

## 三、第一次播放操作

1. 在 hosplayer 首页点开分类媒体库或使用搜索框查找影片，点击海报进入详情页。
   [截图占位：hosplayer 媒体库海报墙与搜索入口界面]

2. 点击详情页的「播放」按钮（剧集点击具体集数），等待几秒缓冲即可开始原画播放。
   [截图占位：hosplayer 影片详情页，框出「播放」按钮与剧集选集区域]

3. 播放时轻触屏幕呼出控制栏，可切换音轨配音或选择字幕；退出播放后观看进度会自动同步回服务器。
   [截图占位：hosplayer 播放控制栏，框出音轨与字幕切换按钮]

## 四、常见问题排查

1. **保存服务器后提示连接失败**
   - 检查地址开头是否为 `https://`、端口是否已改成 `443`（不要保留 `8096`），并确认域名末尾没有多加 `/emby` 或空格。
2. **极个别冷门老片播放无画面或无声音**
   - 本站采用原画直放（不提供服务器端实时压缩转码），依赖设备硬件解码；若极个别特殊封装在当前版本硬解受限，可在片库尝试同影片的其他清晰度版本。
3. **提示账号密码错误或登录设备已满**
   - 请在门户「播放器接入」页核对用户名与播放密码（可点「修改播放密码」重置）；若提示设备数量达上限，打开门户导航栏「我的」页，在「我的设备」卡片中移除旧设备。
