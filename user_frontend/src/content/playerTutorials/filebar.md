# Filebar（原 Fileball）连接与播放教程（iPhone / iPad / Apple TV）

> 适用设备：iPhone、iPad、Apple TV
> 核验日期：2026-11-07

适合使用 iPhone、iPad 或 Apple TV，习惯传统远程连接管理且希望免费基础看片或一次性买断的用户。

## 一、下载与费用说明

- **下载渠道**：打开 iPhone、iPad 或 Apple TV 上的 App Store（国区、美区均可），搜索 `Filebar` 下载，或访问官方商店链接：[App Store - Filebar](https://apps.apple.com/cn/app/filebar/id1558391784)（官方常见问题页：`https://fileball.app/faq`）。
- **费用说明**：软件免费下载，仅连接 Emby 基础观看使用免费版即可；如需高级功能可在应用内买断 Pro 版（参考价约 ¥68）。

1. 打开设备上的 App Store，搜索 `Filebar` 并点击获取安装。

## 二、添加服务器

连接前请先登录网页门户，点击右上角个人头像菜单（或首页右上角按钮）进入「播放器接入」页面（账号权益与设备管理可在导航栏「我的」页查看）。

1. 在门户「播放器接入」页「客户端连接凭据」卡片中复制三样信息（首次进入请先设置专属用户名和播放密码）：
   - **服务器地址**：`https://emby.fluxquata.com`（帆桥会员可用 `https://emby.fanqiao.net`）
   - **用户名**：你的专属播放用户名
   - **播放密码**：你的播放密码（专门给播放器用的独立密码，不是网页登录密码）
   [截图占位：门户「播放器接入」页「客户端连接凭据」卡片，框出服务器、用户名、播放密码三行及复制按钮]

2. 打开 Filebar，进入「连接」页面，点击右上角加号选择「添加远程连接」，在媒体服务器中选择 `Emby`。
   [截图占位：Filebar 添加远程连接列表页，框出媒体服务器下的「Emby」选项]

3. 在添加 Emby 表单中逐项核对填写：
   - **名称**：随意填写（如 `主站影院` 或 `帆桥影院`）
   - **协议 / 地址**：若分栏，协议选 `HTTPS`（加密连接），服务器地址填纯域名 `emby.fluxquata.com`（帆桥会员填 `emby.fanqiao.net`）；若为单一完整地址栏，填 `https://emby.fluxquata.com`，末尾**不要**加 `/emby`
   - **端口**：**必须修改为 `443`**（不要保留默认的 `8096` 或 `8920`）
   - **用户名**：粘贴门户复制的用户名
   - **密码**：粘贴门户复制的播放密码
   [截图占位：Filebar 添加 Emby 服务器表单页，重点框出「HTTPS」「纯域名」「端口 443」与用户名密码栏]

4. 点击右上角「完成 / 保存」，等待软件连接并加载本站分类媒体库。
   [截图占位：Filebar 连接成功后的媒体库分类首页]

## 三、第一次播放与播放内核建议

1. 在 Filebar 中点开刚添加的服务器，选择电影或剧集海报进入详情页，点击「播放」按钮开始观看。
   [截图占位：Filebar 影片详情页，框出「播放」按钮与分集列表]

2. 播放时轻触屏幕呼出控制菜单，可切换音轨与字幕轨道。
   [截图占位：Filebar 播放控制菜单，框出音轨与字幕切换按钮]

3. **字幕显示建议（切换 MPV 播放内核）**：
   - **什么是播放内核**：播放内核是软件内部负责解码画面和渲染字幕的底层引擎。
   - Filebar 默认使用 `VLC` 内核，全屏播放部分带排版特效的动漫或双语字幕时可能出现边缘裁切。建议进入 Filebar「设置 -> 播放器」，将默认播放器切换为 **`MPV`** 内核，字幕与高码率视频兼容性更好。
   [截图占位：Filebar「设置 -> 播放器」页面，框出将播放内核从 VLC 切换为「MPV」的选项]

## 四、常见问题排查

1. **添加服务器时提示无法连接到服务器**
   - 请检查协议是否选了 `HTTPS`、端口是否已从 `8096` 改成 `443`，以及域名是否多填了 `/emby` 或空格。
2. **提示账号或密码错误**
   - 确认输入的是门户「播放器接入」页设置的用户名和「播放密码」，不是门户登录邮箱和网站密码；可在「播放器接入」页点击「修改播放密码」重置。
3. **提示登录设备数已满**
   - 进入网页门户导航栏「我的」页，在「我的设备」卡片中移除不再使用的旧设备后再重新连接。
